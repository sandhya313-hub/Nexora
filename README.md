\# NEXORA



\### Skill Intelligence Platform



Nexora is an AI-powered learning intelligence platform that helps learners understand learning materials, ask questions using uploaded documents, and evaluate their knowledge through AI-generated assessments.



\## ✨ Features



\- 📚 Upload and process learning materials

\- 🔎 Semantic search over uploaded documents

\- 🤖 AI-powered question answering

\- 📝 AI-generated assessments

\- 📊 Assessment scoring and evaluation

\- 🧠 Adaptive competency tracking

\- 📈 Learning analytics

\- 🎯 Competency-based learning insights



\## 🛠️ Tech Stack



\- Python

\- Streamlit

\- Google Gemini API

\- Sentence Transformers

\- FAISS

\- PyPDF

\- NumPy

\## 🚀 Running Locally



\### 1. Clone the repository



git clone https://github.com/sandhya313-hub/Nexora.git



cd Nexora



\### 2. Create a virtual environment



python -m venv venv



\### 3. Activate it



Windows:



venv\\Scripts\\activate



\### 4. Install dependencies



pip install -r requirements.txt



\### 5. Configure your API key



Create a `.env` file:



GOOGLE\_API\_KEY=your\_api\_key\_here



\### 6. Run Nexora



streamlit run app.py



\## 🔐 Environment Variables



The following variables are required:



GOOGLE\_API\_KEY



Never commit your `.env` file or API keys to GitHub.
